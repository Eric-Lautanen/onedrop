# ONE DROP — server

Local static server + desktop-app launcher. No dependencies beyond what
Windows already ships (PowerShell + Edge); Python is optional.

| file | what it is |
|---|---|
| `onedrop.bat` | double-click launcher the desktop icon points at |
| `launch-app.ps1` | starts the server hidden, opens the game in an Edge `--app` window (borderless, **maximized, not fullscreen**), finds Edge via the Windows App Paths registry |
| `serve.ps1` | PowerShell static server. `-WaitWindow` arms the idle watchdog: the game pings `/ping` every 5 s while its window lives, and 20 s of silence shuts the server down |
| `serve.py` | same server in pure stdlib Python (`--app-window` opens the same Edge window and watches the same heartbeat), for machines with Python |
| `serve.sh` | macOS/Linux front end: runs `serve.py` when Python exists, else the PowerShell server (Windows-only fallback) |
| `onedrop.ico` | the desktop icon's artwork (regenerated by `dev/make_desktop_icon.ps1`) |

## Desktop icon

`dev/Create-DesktopIcon.ps1` puts **ONE DROP Pinball** on the Desktop,
pointed at `onedrop.bat`. Close the game window → pings stop → 20 s
grace → the server exits itself. Nothing to keep running, nothing to
kill by hand.

## Manual runs

~~~bat
server\onedrop.bat                       REM the app experience
powershell -File server\serve.ps1        REM plain browser + visible console
python server\serve.py --port 9000       REM plain server from Python
~~~
